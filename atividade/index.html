Sobre o Sistema

Este painel permite o monitoramento em tempo real do conforto ambiental e da ocupação de uma sala inteligente.

Objetivo: Otimizar a utilização do espaço e garantir um ambiente climatizado adequado para os ocupantes com base nas leituras dos sensores.

Tecnologias Utilizadas:

  • HTML5, CSS3, JavaScript (Frontend)
  • Supabase (Autenticação e Banco de Dados)
  • ESP32 (Microcontrolador C++)
  • Sensores DHT22 (Temperatura) e PIR (Movimento)
  • MQTT (Comunicação via Broker EMQX)
  • GSAP (Animações Dinâmicas)
